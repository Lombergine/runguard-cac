RunGuard

Injury-load tracking that tests its own score.

An app for high-school cross-country runners and their coaches. It shows the same workload ratio every running app shows, then checks on your own data whether that number deserves to be trusted.

For runners
Your own threshold instead of a universal cutoff, a self-audit with a confidence interval, a camera gait check that runs on the phone.
For coaches
The 2021 Impellizzeri experiment rerun on the team's injury log, and a model learned from the team, scored on athletes it never saw.
Checked
Every statistic verified against a Python reference in 51 tests. The AI explanation layer may only repeat numbers the server computed.
